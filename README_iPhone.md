# 社労士 一問一答 v3.0.1 iPhone対応版

## iPhoneで直接HTMLを開けない理由
iPhoneの「ファイル」アプリからHTMLを開くと、Safariではなくプレビュー表示になり、
JavaScriptや同梱データが正常に動作しないことがあります。
そのため、この版はWebサイトとして公開してSafariで開く方式です。

## GitHub Pagesで公開する手順
1. このフォルダ内のファイルをGitHubリポジトリのルートへアップロードします。
2. GitHubの Settings → Pages を開きます。
3. Build and deployment の Source を「Deploy from a branch」にします。
4. Branch を main、Folder を /(root) にして Save します。
5. 数分後に表示されるURLをiPhoneのSafariで開きます。
6. Safariの共有ボタン →「ホーム画面に追加」でアプリのように使えます。

## 注意
- ZIPのままでは開けません。必ず展開してアップロードしてください。
- GitHub PagesのURLは https:// で始まります。
- 学習履歴はiPhoneのSafari内に保存されます。
